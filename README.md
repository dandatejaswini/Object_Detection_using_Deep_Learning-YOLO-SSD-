# Self-Driving Cars Bootcamp - Day 3 🚗

This is my **Day 3 AI Bootcamp project**, where I worked on **object detection** using the **YOLOv8 model** with a **self-driving car dataset** from Kaggle.

## 📘 Project Overview
- Downloaded and explored the *Self-Driving Cars* dataset from Kaggle.  
- Visualized bounding boxes for different detected objects.  
- Used **Ultralytics YOLOv8** for real-time object detection.  
- Displayed detection results, object classes, and confidence scores.

## 🧠 Technologies Used
- Python  
- OpenCV  
- Pandas  
- Matplotlib  
- Ultralytics YOLOv8  
- Google Colab  

## 📂 Dataset
[Kaggle - Self-Driving Cars Dataset](https://www.kaggle.com/datasets/alincijov/self-driving-cars)
